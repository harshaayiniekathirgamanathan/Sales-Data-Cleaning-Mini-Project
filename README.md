# Sales Data Cleaning Mini Project

## Project Overview
A mini project focused on cleaning a messy sales dataset using Python and Pandas.

## Technologies Used
- Python
- Pandas
- NumPy
- Google Colab

## Cleaning Tasks
- Handling missing values
- Detecting outliers
- Removing duplicates
- Correcting data types
- Standardizing text
- Handling inconsistent dates
- Creating TotalAmount column

## Formula
TotalAmount = Quantity * UnitPrice
